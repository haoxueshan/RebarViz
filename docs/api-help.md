# AI 助手 API 配置说明

这份文档是给第一次接触 AI 接口的用户准备的。

如果你不知道什么是 API、API Key、为什么配置了还是不能用，先看这里。

## 1. API 是什么

`API` 可以理解成“程序调用 AI 服务的入口”。

本项目里的 AI 助手，并不是直接内置在网页里的，它需要去调用第三方 AI 服务商的模型，例如：

- `DeepSeek`
- `通义千问 Qwen`
- `Kimi`
- `OpenAI`

调用这些服务时，需要两样东西：

1. `API Key`
2. 账户余额 / 可用额度

## 2. API Key 是什么

`API Key` 就像一把“调用权限钥匙”。

你在服务商官网创建 API Key 后，把它填到 RebarViz 的「设置」页面里，项目才能代表你去调用该服务商的模型。

注意：

- `API Key 不是 Chat 网页版会员`
- `API Key 也不是手机号验证码`
- `API Key 一般只在服务商自己的开发者平台里生成`

## 3. 为什么配置了 Key 还不能用

最常见的原因有 4 个：

1. `Key 填错了`
2. `Key 已失效`
3. `账号没有余额 / 没有开通计费`
4. `当前模型没有权限访问`

其中第 3 条最常见。

很多用户以为“创建了 API Key 就一定能用”，其实不是。

大多数 AI 服务商的 API 都是`按调用计费`的：

- 只创建 Key，不代表已经有额度
- 账户没有余额时，接口会直接报错
- 充值通常要在各服务商自己的官网后台完成

## 4. 充值在哪里充

`充值不是在 RebarViz 里充`

`充值是在各 AI 服务商官网充`

常见入口：

- `DeepSeek`：在 DeepSeek 开发者平台充值 / 开通计费
- `通义千问 Qwen`：在阿里云 DashScope 后台充值 / 开通服务
- `Kimi`：在月之暗面开放平台充值 / 开通计费
- `OpenAI`：在 OpenAI Platform 后台绑定支付方式并充值或开通 billing

你需要登录你自己的服务商账号，在对应平台里完成：

1. 注册 / 登录
2. 开通 API 服务
3. 充值或绑定支付方式
4. 创建 API Key
5. 回到 RebarViz 设置页面粘贴 Key

## 5. 正确使用流程

推荐按下面顺序操作：

1. 选择一个服务商
2. 去该服务商官网注册开发者账号
3. 确认该账号已经有可用余额或已开通计费
4. 创建 `API Key`
5. 打开 RebarViz 左侧导航的「设置」
6. 粘贴 `API Key`
7. 点击「测试连接」
8. 测试通过后再使用 AI 助手

## 6. 各服务商配置建议

### DeepSeek

适合：

- 日常问答
- 构造规则解释
- 成本敏感场景

注意：

- 需要在 DeepSeek 开放平台创建 API Key
- 需要确认账户里有余额

### 通义千问 Qwen

适合：

- 多模型切换
- 中文体验
- 图纸识别场景

注意：

- 需要在阿里云 DashScope 后台开通
- 需要在阿里云侧完成计费和余额准备

### Kimi

适合：

- 长上下文
- 长文本解析

注意：

- 需要在月之暗面开放平台创建 API Key
- 同样需要确认账户额度

### OpenAI

适合：

- 视觉识别
- 通用稳定性

注意：

- 要在 OpenAI Platform，不是 ChatGPT 网页版里配置
- 需要绑定 billing / 支付方式，或确认有可用余额

## 7. 在 RebarViz 里如何配置

进入：

- 左侧导航栏 `设置`

你会看到每个服务商的卡片。

常用按钮说明：

- `获取 Key`：跳转到服务商官网
- `+ 添加 API Key`：填写你的 Key
- `保存`：保存到浏览器本地
- `测试连接`：检测这个 Key 当前能不能调用模型

## 8. “测试连接失败”怎么办

可以按这个顺序排查：

1. 检查是否多复制了空格
2. 检查 Key 是否复制完整
3. 去服务商官网确认 API 是否已开通
4. 去服务商官网确认账户是否有余额
5. 检查当前默认模型是否对你的账号可用
6. 重新生成一个新的 API Key 再试

## 9. 安全提醒

`不要把 API Key 发给别人`

`不要把 API Key 提交到 Git 仓库`

本项目当前设计为：

- API Key 只保存在你的浏览器本地
- 不会被上传到 RebarViz 服务器保存
- 调用时只发送给你选定的 AI 服务商

但你仍然应该把它当成密码一样保管。

## 10. 常见误区

### 误区 1：我开了 Chat 会员，为什么 API 不能用？

因为`聊天会员`和`开发者 API`通常是两套计费体系。

### 误区 2：我能在 RebarViz 里直接充值吗？

不能。

充值要去`各服务商官网`完成。

### 误区 3：我只要有 Key 就一定能调用成功？

不一定。

如果没余额、没开通服务、模型没权限，仍然会失败。

## 11. 推荐给新手的最短路径

如果你只想尽快用起来：

1. 选一个服务商
2. 去官网充值 / 开通计费
3. 创建 API Key
4. 粘贴到 RebarViz 设置
5. 点击测试连接
6. 成功后再开始用 AI 助手

## 12. 一句话总结

`API Key 只是钥匙，账户余额才是油箱。`

没有余额，很多接口就算 Key 正确也跑不起来。
