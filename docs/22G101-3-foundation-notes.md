## 对当前产品最有价值的构造点

### 独立基础

- 平面注写至少包含：编号、竖向尺寸、配筋。
- 双柱独立基础需要单独处理柱间顶部受力筋和分布筋。
- 大尺寸底板可采用“隔一布一减短 10%”的构造，但图中应明确说明。
- 柱插筋进入基础的直锚 / 弯锚，应和 `2-10` 页统一判断。

### 条形基础

- 条形基础底板配筋分底部 `B` 和顶部 `T`。
- 双梁或双墙共用底板时，除底板底筋外，中间区域顶部钢筋也要单独交代。
- 条形基础两侧宽度可不对称，原位标注优先于集中标注。

### 筏形基础

- 应先区分梁板式还是平板式，再区分 JL / JCL / LPB / ZXB / KZB / BPB。
- 边支座锚固、同层交叉筋上下关系、边缘侧面封边，是图纸最容易漏写的点。
- 梁板式和条形基础共享一部分 JL / JCL 梁类构造逻辑，但不能直接套用普通框架梁规则。
- 局部板厚增加 JBH 应与柱插筋锚固、板带范围一并判断。

### 桩基础

- 圆桩承台底筋端部常用判据：`25d + 0.1D` 和 `35d + 0.1D`。
- 桩顶进入承台高度：桩径或边长 `< 800mm` 取 `50mm`，`>= 800mm` 取 `100mm`。
- 双柱联合承台与单柱承台的顶部配筋逻辑不同，应分开处理。
- 灌注桩螺旋箍、加劲箍和桩顶连接构造，应与承台一体看。

## 设计需写明

OCR 附表 `2-61` 对产品设计很重要，建议所有 AI 问答和后续规则引擎优先覆盖以下内容：

1. 墙身外侧竖向分布钢筋与基础底部纵筋搭接连接做法：`2-8`
2. 筏形基础平板底部钢筋在边支座的锚固要求：`2-33、2-37`
3. 基础平板同一层面交叉纵筋的上下关系：`2-32、2-33、2-34、2-35`
4. 基础梁相交处同层交叉纵筋的上下关系：`2-23`
5. 仅将柱四角纵筋伸至底板钢筋网片上：`2-10`
6. 基础梁 / 基础次梁底部纵筋多于两排时，从第三排起非贯通筋伸入跨内长度：`2-23、2-29`

## 未注明时的默认 / 可选做法

同样来自附表 `2-61`：

- 筏板边缘侧面封边构造未写明时，可由施工单位选做：`2-37`
- 拉筋弯钩构造未写明时，采用封闭箍筋：`2-7`
- 基础梁 / 基础次梁外伸部位箍筋未写明时，按梁端第一种箍筋设置：`2-25、2-29`
- 灌注桩焊接加劲箍未注明时，直径取 `12mm`，强度等级不低于 `HRB400`：`2-46、2-47`
